# 디자인 자산 넣는 곳

이미지개미가 납품한 `03_앱적용` 파일을 **같은 파일명 그대로** 이 폴더에 복사하고 `npm run build`(또는 배포 빌드)를 다시 하면 적용됩니다.
파일이 없으면 코드로 그린 임시 디자인이 보입니다. 규격: `docs/NAME_ATELIER_DESIGN_SPEC.md` §8.

| 파일 | 적용 위치 |
|---|---|
| bg_main_light.jpg / bg_main_dark.jpg | 창 배경 (둘 다 있어야 적용) |
| card_frame_light.png / card_frame_dark.png | 이름 카드 9-slice 테두리 (둘 다 있어야 적용) |
| card_crest.png | 카드 상단 장식 |
| card_back.png | 카드 뒷면 |
| logo_wordmark_dark.png / logo_wordmark_light.png | 머리 로고 (둘 다 있어야 적용) |
| logo_symbol.png | 머리 심볼·정보창 |

앱 아이콘은 `assets/icon/` (app_icon.ico, app_icon.icns, app_icon_256.png).
