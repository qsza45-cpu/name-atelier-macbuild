# NAME ATELIER — Mac 설치·실행 설명서

NAME ATELIER Mac 버전은 **Apple 공증(인증)을 받지 않은 무료 배포판**입니다. 그래서 처음 열 때 macOS가 "확인되지 않은 개발자" 경고를 띄웁니다. 아래 순서대로 한 번만 허용하면 그다음부터는 바로 열립니다. 인터넷 연결이나 Apple 계정은 필요 없습니다.

## 1. 내 Mac에 맞는 파일 고르기

화면 왼쪽 위  메뉴 → **이 Mac에 관하여**에서 확인합니다.

| 표시 | 받을 파일 |
|---|---|
| **칩: Apple M1 / M2 / M3 / M4 …** | `NAME ATELIER-0.2.0-arm64.dmg` |
| **프로세서: Intel …** | 이번 0.2.0 배포에는 Intel용이 없습니다. 필요하면 배포자에게 요청해 주세요. |

## 2. 설치

1. `.dmg` 파일을 더블클릭해서 엽니다.
2. 열린 창에서 **NAME ATELIER** 아이콘을 **응용 프로그램(Applications)** 폴더로 끌어다 놓습니다.
3. 창을 닫고, Finder 왼쪽의 디스크 아이콘 옆 ⏏를 눌러 꺼냅니다.

(`.zip`을 받았다면 더블클릭으로 풀고, 나온 **NAME ATELIER** 앱을 응용 프로그램 폴더로 옮기면 됩니다.)

## 3. 처음 열기 — 실행 허용

### macOS 15 (Sequoia) 이상

1. 응용 프로그램 폴더에서 **NAME ATELIER**를 더블클릭합니다.
   → "Apple은 'NAME ATELIER'에 Mac에 손상을 입히거나 개인 정보를 침해할 수 있는 악성 코드가 없음을 확인할 수 없습니다." 창이 뜨면 **완료**를 누릅니다. (이 단계는 꼭 한 번 거쳐야 아래 버튼이 나타납니다.)
2.  메뉴 → **시스템 설정** → 왼쪽 **개인정보 보호 및 보안**을 엽니다.
3. 아래로 내려 **보안** 부분에 있는 「'NAME ATELIER'이(가) Mac을 보호하기 위해 차단되었습니다」 옆의 **그래도 열기**를 누릅니다.
4. Mac 로그인 암호(또는 Touch ID)를 입력합니다.
5. 다시 뜨는 창에서 **그래도 열기**를 누르면 실행됩니다.

### macOS 14 (Sonoma) 이하

1. 응용 프로그램 폴더에서 **NAME ATELIER**를 **Control 키를 누른 채 클릭**(또는 오른쪽 클릭)합니다.
2. 메뉴에서 **열기**를 고릅니다.
3. 경고 창에서 **열기**를 누릅니다.

## 4. "손상되었기 때문에 열 수 없습니다"가 뜰 때

인터넷에서 받은 파일에 붙는 격리 표시 때문입니다. 파일이 실제로 망가진 것은 아닙니다.

1. **응용 프로그램 → 유틸리티 → 터미널**을 엽니다.
2. 아래 한 줄을 그대로 붙여 넣고 Enter를 누릅니다(암호를 묻지 않습니다).

```bash
xattr -cr "/Applications/NAME ATELIER.app"
```

3. 다시 3번 순서로 엽니다.

## 5. 인증키 입력

Windows 버전과 똑같습니다. 처음 실행하면 **인증키 입력** 화면이 나오니 받은 키를 붙여 넣고(⌘V 또는 「붙여넣기」) **인증하기**를 누르세요. Windows에서 쓰던 같은 인증키를 Mac에서도 쓸 수 있습니다. 한 번 인증하면 다음부터는 묻지 않습니다.

## 6. 알아 두세요

- 이 경고는 Apple 개발자 계정(연 $99)으로 공증하지 않았기 때문에 나옵니다. 프로그램은 인터넷에 접속하지 않고 이 Mac 안에서만 작동합니다.
