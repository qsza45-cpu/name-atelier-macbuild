# NAME ATELIER — 디자인 제작 규격서 v1

작성 2026-10-28 (KST) · 개발 세션 작성 · 대상: 이미지개미(디자인 자산 제작)

이 문서는 실제 개발 구조(Electron + React, 코드 렌더링 UI)에 맞춘 규격입니다. 함께 볼 문서:

- 이미지 생성 프롬프트: `NAME_ATELIER_IMAGE_PROMPTS.md`
- 화면 배치 와이어프레임: `design/NAME_ATELIER_UI_WIREFRAME.svg` (치수 표기 포함)

**변경 반영:** 한 번에 이름 **3개**를 생성합니다. 화면 중앙에 이름 카드 3장, 그 아래에 크고 눈에 띄는 「다시 뽑기 ✨」 버튼이 있습니다. 10개 목록 화면은 없습니다.

**변경 반영 2:** 캐릭터 이름 전용입니다(지명·가문·문파·기술명 없음). 이름 스타일은 10종입니다: 한국식 · 로판식 · 선협식 · 무협식 · 미국식 · 영국식 · 프랑스식 · 독일식 · 일본식 · 창작 판타지식. 선협식·무협식 카드는 둘째 줄에 한자 표기(예 `白蓮花`)가 나옵니다. 스타일은 **한국**(한국식) · **동양풍**(선협식·무협식·일본식) · **서양풍**(로판식·미국식·영국식·프랑스식·독일식·창작 판타지식) 세 분류로 먼저 고릅니다.

## 0. 역할 분담 원칙

| 구분 | 담당 | 예 |
|---|---|---|
| 브랜드·분위기 자산 | **이미지개미 (PNG/JPG/SVG)** | 로고, 앱 아이콘, 배경, 카드 테두리 장식, 카드 뒷면 |
| 모든 글자·조작 요소 | **코드 (HTML/CSS)** | 버튼, 선택 칩, 이름 텍스트, 하단 메뉴, 즐겨찾기 서랍, 대화상자, 아이콘 버튼 |

- 이미지 안에 **글자를 넣지 않습니다.** (로고 워드마크 제외)
- 버튼·칩·입력창 모양을 PNG로 만들지 않습니다. 색·모서리·그림자는 코드 디자인 토큰으로 처리합니다.
- 자산이 하나도 없어도 프로그램은 작동합니다. 자산은 넣으면 바로 덧씌워지는 구조입니다.

## 2. 배경 이미지

| 자산 | 크기 | 비율 | 형식 | 용량 |
|---|---|---|---|---|
| `bg_main_light.jpg` | **3200 × 2000** | 16:10 | JPG (q 80–85, sRGB, 점진적 아님) | ≤ 900 KB |
| `bg_main_dark.jpg` | **3200 × 2000** | 16:10 | JPG | ≤ 900 KB |

- 배치: `background-size: cover; background-position: center`. 창 비율이 바뀌면 **가장자리가 잘립니다.**
- **중앙 안전 영역:** 가운데 **2240 × 1400** (가로 70%, 세로 70%) 바깥에만 장식을 둡니다. 안전 영역 안은 낮은 대비의 질감(종이결·은은한 빛)만 허용합니다. 이 위에 카드 3장과 글자가 올라갑니다.
- **잘림 고려:** 최소 창(760×600, 약 1.27:1)에서는 좌우가 각각 약 10% 잘립니다. 최대화 16:9에서는 위아래가 각각 약 5% 잘립니다. 중요한 장식은 모서리에서 **안쪽 12%** 이상 떨어뜨리지 마세요(너무 바깥이면 잘리고, 너무 안쪽이면 카드를 침범).
- 배경 위에는 코드가 반투명 막(라이트 0–8%, 다크 0–12%)을 씌울 수 있습니다. 배경 자체를 너무 어둡거나 화려하게 만들지 마세요.
- 이미지가 없으면 코드의 그라데이션 배경이 보입니다.
- PNG가 아닌 JPG인 이유: 투명이 필요 없고 사진 같은 질감이라 용량이 1/4 수준입니다.

### 4-2. 긴 이름 처리
- 한글 8자 이하는 30px 한 줄. 9–14자는 24px로 줄이고 필요하면 성과 이름 사이에서 줄바꿈(2줄). 15자 이상은 20px 2줄 + 말줄임(전체 이름은 마우스를 올리면 보이고, 복사는 전체).
- 예시 최장 사례: `엘리자베스 샬럿 펨버턴` / `프리드리히 폰 아이헨도르프`.
- 그래서 카드 장식은 **글자 안전 영역(212×268)을 절대 침범하면 안 됩니다.**

### 4-3. 카드 자산

| 자산 | 크기 | 형식 | 설명 |
|---|---|---|---|
| `card_frame_light.png` | **792 × 960** (264×320 @3x) | PNG 투명 | 9-slice 테두리. 사방 inset **54 px**(@3x) 안에만 장식. **inset 안쪽 중앙은 완전 투명(alpha 0)** |
| `card_frame_dark.png` | 792 × 960 | PNG 투명 | 위와 같은 구조, 다크용 색 |
| `card_crest.png` | **360 × 84** (120×28 @3x) | PNG 투명 | 카드 상단 가운데 작은 문장(紋章)·꽃장식. 라이트·다크 공용 (금빛) |
| `card_back.png` | **792 × 960** | PNG (불투명 가능, 모서리 18@1x 둥글게 투명) | 카드 뒷면 무늬. 뽑기 애니메이션에서 카드가 뒤집힐 때 잠깐 보임. 라이트·다크 공용 |

**9-slice 규칙 (card_frame):**
- 네 모서리 54×54(@3x) 영역은 크기가 변해도 그대로 유지됩니다 → 모서리 장식은 이 칸 안에 완결.
- 네 변(모서리 사이)은 **늘어납니다** → 변에는 반복·늘려도 어색하지 않은 단순한 선만. 변 가운데에 점·꽃 같은 단일 장식 금지(늘어나면 찌그러짐).
- 카드 바탕색(종이색)은 코드가 칠합니다. 프레임은 테두리 장식만.
- 최소 카드 208×300에서도 모서리 장식끼리 겹치지 않아야 합니다(모서리 18 + 18 < 208).

### 4-4. 카드 상태
| 상태 | 처리 (코드) |
|---|---|
| 기본 | 카드 바탕 + 프레임 |
| 마우스 올림 | 살짝 떠오름(그림자 강화, 2px 위로) |
| 즐겨찾기됨 | ★ 채움(액센트 색), 카드 우상단에 작은 리본 표시는 **코드 CSS**로 |
| 고정(즐겨찾기한 카드는 다시 뽑아도 유지) | "보관됨" 작은 배지 (코드) |
| 빈 카드(처음 실행) | `card_back.png` 앞면을 보여 주고 "이름을 뽑아 보세요" 문구(코드) |

### 4-5. 애니메이션
- 다시 뽑기: 기존 카드가 뒤집혀 `card_back` → 새 이름 앞면 (카드마다 60ms 시차, 총 약 450ms).
- 설정에서 끌 수 있고, 운영체제의 "애니메이션 줄이기" 설정을 따릅니다. 꺼지면 즉시 교체.
- 반짝임(✨) 효과는 코드(CSS)로 처리합니다. 별도 이미지 불필요.
