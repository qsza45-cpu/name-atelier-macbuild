# NAME ATELIER 인증키 생성기 — 관리자 설명서

**관리자 전용 프로그램입니다. 사용자에게 보내거나 사용자 배포 ZIP에 넣지 마세요.**

## 1. 실행

`NAME_ATELIER_Keygen_1.0.0_Windows.zip`의 압축을 풀고 `NAME ATELIER Keygen.exe`를 실행합니다. 인터넷 연결이 필요 없습니다.

## 2. 서명 키 (가장 중요)

인증키는 **서명 비밀키**로 만들고, NAME ATELIER는 프로그램 안에 넣어 둔 공개키로 확인합니다.

- **이 컴퓨터에는 이미 서명 키가 만들어져 있습니다**(2026-10-28, 지문 `4789-7E8C-880D-D2EF` — 생성기 화면 위쪽 「지문」에 표시). 지금 배포하는 NAME ATELIER 0.2.0은 이 키로 만든 인증키만 받아들입니다. 생성기 화면에 「배포용 NAME ATELIER와 맞는 서명 키입니다」라고 나오면 정상입니다.
- 서명 키는 `%APPDATA%\NAME ATELIER Keygen\signing-key.json`에 **이 Windows 계정에서만 열 수 있도록 암호화되어** 저장됩니다. 다른 Windows 계정이나 다른 컴퓨터에서는 이 파일만으로 열 수 없습니다.

### 반드시 백업하세요

1. 생성기에서 **「비밀키 백업 저장」**을 누르고 `NAME_ATELIER_서명비밀키_백업_날짜.pem` 파일을 저장합니다.
2. 이 파일을 **USB 등 오프라인 저장소 두 곳**에 보관합니다(예: USB 2개, 또는 USB + 금고/외장 디스크).
3. 백업을 만든 뒤 컴퓨터의 임시 위치(바탕화면·다운로드 등)에 남은 사본은 지웁니다.

- 백업 파일은 **암호화되어 있지 않습니다.** 이 파일이 있으면 누구나 NAME ATELIER 인증키를 만들 수 있습니다.
- 인터넷 드라이브·메일·메신저·노션·Git 저장소에 올리지 마세요.

### 비밀키를 잃으면

- 서명 키(이 컴퓨터의 파일과 백업 모두)를 잃으면, **이미 배포한 NAME ATELIER가 받아들이는 새 인증키를 더 이상 만들 수 없습니다.**
- 새 서명 키를 만들 수는 있지만, 그 키로 만든 인증키는 **새 공개키를 넣어 다시 빌드한 NAME ATELIER에서만** 통합니다. 기존 버전 사용자는 새 버전을 받아야 합니다.
- 이미 사용자에게 준 인증키는 서명 키를 잃어도 계속 작동합니다(프로그램이 공개키로만 확인하기 때문).

### 다른 컴퓨터로 옮기거나 다시 설치할 때

새 컴퓨터에서 생성기를 실행하면 「서명 키가 없습니다」가 나옵니다. **「백업에서 불러오기」**로 백업 파일을 고르세요. 지문이 원래 지문과 같으면 정상입니다.
**「새 서명 키 만들기」는 누르지 마세요**(배포된 NAME ATELIER와 맞지 않는 키가 생깁니다. 생성기도 경고합니다).

## 3. 인증키 만들기

1. 「개수」에 1~100을 넣고 **생성**을 누릅니다. 모두 서로 다른 인증키이고, 각각 고유한 **키 ID**(예: `3F9A-27C1-88D0-4E12`)가 들어 있습니다.
2. **목록 복사** · **TXT 저장**(인증키만 한 줄씩) · **CSV 저장**(번호·키 ID·인증키·생성일, 엑셀용)으로 보관합니다.
3. 목록은 저장하지 않으면 창을 닫을 때 사라집니다. 누구에게 어떤 키를 줬는지는 CSV의 키 ID로 관리하세요.

## 4. 인증키의 성질 (오프라인 방식의 한계)

- 같은 인증키를 여러 컴퓨터에서 쓸 수 있습니다. 사용 횟수·만료일·컴퓨터 수 제한은 없습니다.
- 서버가 없으므로 **이미 준 키를 원격으로 막거나, 누가 쓰는지 조회하거나, 키가 공유되는 것을 막을 수 없습니다.**
- 사용자 프로그램 파일 자체를 고쳐서 인증을 건너뛰는 것까지 완전히 막는 장치(DRM)는 아닙니다. 정상적인 사용자가 인증키 없이는 쓸 수 없게 하는 수준입니다.
- 사용자 프로그램에는 공개키만 들어 있고, 비밀키나 인증키를 만드는 기능은 들어 있지 않습니다(배포 전 자동 검사로 확인).

## 5. 사용자에게 안내할 내용

- NAME ATELIER를 처음 실행하면 인증키 입력 화면이 나옵니다. 받은 키를 그대로 붙여 넣고 「인증하기」를 누르면 됩니다(앞뒤 공백·줄바꿈·하이픈은 상관없음).
- 한 번 인증하면 다음부터는 묻지 않습니다. 인증 정보 파일이 손상되면 다시 입력하라는 안내가 나오고, 즐겨찾기·설정은 그대로 남습니다.
