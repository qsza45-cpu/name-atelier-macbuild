# NAME ATELIER — 작명 아틀리에 사용 설명서

웹소설 캐릭터 이름을 한 번에 세 개씩 뽑아 주는 작은 프로그램입니다. 인터넷 연결, 로그인, 회원가입이 필요 없고 구독료도 없습니다.

## 설치

**Windows**
- 압축판: `NAME_ATELIER_0.2.0_Windows.zip`의 압축을 풀고 `NAME ATELIER\NAME ATELIER.exe`를 실행합니다. 설치가 필요 없습니다.
- 설치판을 받은 경우: `NAME-ATELIER-Setup-0.2.0.exe`를 실행합니다. 설치 위치를 고를 수 있습니다.
- 코드 서명이 없는 무료 배포판이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요.

**macOS** — 준비 중입니다. 공증 전 단계라 첫 실행 때 경고가 뜰 수 있습니다. 그때는 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 누르세요.

## 처음 실행 — 인증키 입력

- 처음 실행하면 **인증키 입력** 화면이 나옵니다. 받으신 인증키를 붙여 넣고(「붙여넣기」 버튼 또는 Ctrl+V) **인증하기**를 누르세요. 앞뒤 공백·줄바꿈이 섞여도 괜찮습니다.
- 한 번 인증하면 다음부터는 묻지 않습니다. 같은 인증키를 여러 컴퓨터에서 쓸 수 있습니다. 인터넷 연결은 필요 없습니다.
- 「형식이 올바르지 않습니다」·「유효하지 않은 인증키입니다」가 나오면 받은 키 전체가 빠짐없이 들어갔는지 확인하세요.
- 인증 정보가 손상되면 다시 입력 화면이 나옵니다. 즐겨찾기·설정·메모는 그대로 남아 있습니다.
- 인증 상태와 키 ID는 **프로그램 정보**에서 볼 수 있습니다.

## 이름 뽑기

1. **장르**를 고릅니다: 판타지 · 로맨스 · 현대물 · 무협
2. **이름 스타일**을 고릅니다. 먼저 분류(**한국 / 동양풍 / 서양풍**)를 누르면 그 안의 스타일이 나옵니다.
   - 한국: 한국식
   - 동양풍: 선협식 · 무협식 · 일본식
   - 서양풍: 로판식 · 미국식 · 영국식 · 프랑스식 · 독일식 · 창작 판타지식
   - 로판식: 로맨스판타지 귀족풍 서양 이름 (원어 철자 함께 표시)
   - 선협식·무협식: 한자 이름 (한자 표기 함께 표시)
3. **성별**을 고릅니다: 남성 · 여성 · 성별 무관
4. **이름 뽑기 ✨**를 누르면 카드 세 장에 이름이 나옵니다. 다시 누르면(**다시 뽑기 ✨**) 새 이름 세 개가 나옵니다.

- 장르는 이름의 분위기(예: 로맨스·판타지는 고전적인 귀족풍 이름, 현대물은 요즘 이름)를 조절합니다. 장르와 스타일은 자유롭게 섞을 수 있습니다.
- 한 번 실행하는 동안 이미 나온 이름은 가능한 한 다시 나오지 않습니다. 후보가 거의 떨어지면 버튼 아래에 안내가 나옵니다.
- **↶ 이전**(단축키 **Z**): 방금 넘긴 세 장으로 되돌아갑니다. 여러 번 누르면 더 앞으로 갑니다.
- **최근**: 이번 실행에서 본 이름 전체(최근 90개)를 보여 줍니다. 여기서도 복사·즐겨찾기를 할 수 있습니다. 프로그램을 끄면 사라집니다.
- 단축키: **R** = 다시 뽑기, **Z** = 이전 뽑기, **Esc** = 열린 창(조건·즐겨찾기·설정 등) 닫기.
- 처음 이름을 뽑으면 버튼 아래에 카드 버튼 안내가 나옵니다. 오른쪽 위 **?** 버튼으로 언제든 사용법을 볼 수 있습니다.

## 작품별 작업 공간

오른쪽 위 **작품** 목록에서 작품을 고르거나 **＋ 새 작품 / 관리…**로 만듭니다.

- 작품마다 장르·이름 스타일·성별·조건 뽑기·피할 이름을 따로 기억합니다. 작품을 바꾸면 그 작품의 설정으로 돌아갑니다.
- 작품을 고른 상태에서 담은 즐겨찾기는 그 작품으로 자동 분류됩니다.
- 즐겨찾기에서 **확정**(작품에 이미 쓴 이름)을 체크하면, 그 작품 작업 공간에서는 같은 이름이나 같은 이름자를 자동으로 피합니다.
- 작업 공간을 지워도 즐겨찾기의 작품 표시는 남습니다.

## 카드에서 할 수 있는 것

카드에는 이름, 원어 표기와 함께 **한자 뜻**(선협식·무협식, 예: `葉 잎 엽 · 霓 무지개 예 · 幽 그윽할 유`)이나 **애칭**(서양 이름, 예: `도러시아 → 애칭 도라 · 도티`)이 나옵니다. 아래쪽 버튼은 왼쪽부터 다음과 같습니다.

- **복사**: 이름을 복사합니다. 외국 이름과 한자 이름은 원어 표기도 함께 복사됩니다. 예: `샬럿 펨버턴 (Charlotte Pemberton)`
- **이미지로 저장**: 카드를 SNS에 올리기 좋은 그림(1080×1350, PNG)으로 저장합니다. NAME ATELIER와 PLOTIVE 로고가 들어갑니다. 세 장을 한 번에 저장하려면 **내보내기 → 지금 카드 3장 이미지로 저장**(1920×1080)을 누르세요.
- **성 고정 🔒**: 이 카드의 성을 고정합니다. 다시 뽑으면 **성은 그대로 두고 이름만** 바뀝니다. 형제자매나 같은 가문 인물을 만들 때 쓰세요. 버튼 아래 「성 고정: ○○ 풀기」로 풀 수 있고, 이름 스타일을 바꾸면 자동으로 풀립니다.
- **즐겨찾기 ☆**: 이름을 보관합니다. 즐겨찾기한 카드는 **다시 뽑아도 그 자리에 남습니다.** 세 장 모두 즐겨찾기했다면 다시 뽑기를 눌렀을 때 세 장 모두 새로 뽑습니다(이름은 즐겨찾기에 그대로 남아 있습니다).

## 조건 뽑기와 피할 이름

성별 줄 오른쪽 버튼입니다. 둘 다 이 컴퓨터에 저장되어 다음에 켜도 유지됩니다.

- **조건 뽑기 — 분위기**: **시대감**(현대적·고전적), **느낌**(부드러운·강한), **개성**(평범한·화려한)을 고릅니다. 이름마다 검수해 붙인 분위기 태그로 고르며, 창작 판타지식은 ‘느낌’만 소리로 판단합니다. 분위기 판단은 작가마다 다를 수 있는 참고 기준입니다.
- **조건 뽑기 — 글자**: 이름(성 제외) 부분의 **글자 수**(1자·2자·3자·4자 이상), **첫 글자**(‘연’처럼 한 글자, 또는 ‘ㅅ’처럼 자음만), **끝 글자 받침**(있음·없음)을 정합니다. 외국 이름은 한글 표기 기준입니다. 조건이 걸려 있으면 버튼에 요약(예: `2자 · ‘ㅅ’ 시작`)이 보입니다.
- **피할 이름**: 작품에 이미 나온 인물 이름을 붙여 넣으면(쉼표·줄바꿈으로 구분) 같은 이름, 같은 이름자(‘유연서’가 있으면 ‘김연서’도), 성만 붙은 이름을 뽑지 않습니다. 띄어 쓴 이름(‘레티시아 로젠베르크’, ‘사토 하루토’)은 이름 부분을 따로 비교하므로 ‘레티시아 랭커스터’도 피합니다. 같은 성만 겹치는 것은 피하지 않습니다(형제·가족 인물용). 입력하면 어떻게 나뉘어 인식됐는지 바로 아래에 보입니다.
- 조건이 너무 좁아 맞는 이름이 없으면 버튼 아래에 안내가 나옵니다.

## 즐겨찾기와 내보내기

- 아래쪽 **즐겨찾기**를 누르면 보관한 이름 목록이 열립니다.
  - **검색**: 이름·원어·메모·작품·한자 뜻·애칭으로 찾습니다.
  - **작품별 보기**: 작품을 고르거나 ‘미분류’만 볼 수 있습니다.
  - **✎ 메모·작품**: 이름마다 작품 이름(예: 천명수선기)과 메모를 붙입니다. 작품별 보기를 고른 상태에서 즐겨찾기하면 그 작품으로 바로 분류됩니다.
  - 이름별로 복사·삭제할 수 있습니다.
- **저장 범위**: 즐겨찾기 창의 TXT·CSV·복사는 **지금 보이는 목록**(검색·작품별 보기 결과)만 저장합니다. 버튼 옆에 「현재 목록 n개」/「전체 n개」로 표시됩니다. 아래쪽 **내보내기** 메뉴는 항상 **즐겨찾기 전체**입니다.
- 즐겨찾기는 5,000개까지 담을 수 있습니다. 4,500개를 넘으면 개수 옆에 한도가 표시됩니다.
- CSV에서 =, +, -, @로 시작하는 메모는 엑셀이 수식으로 실행하지 않도록 앞에 '를 붙여 저장합니다.
- **내보내기**: 즐겨찾기를 TXT 또는 CSV(엑셀용)로 저장하거나 전체를 복사합니다. 메모·작품·한자 뜻·애칭도 함께 들어갑니다. 지금 카드 세 장을 복사하거나 이미지로 저장할 수도 있습니다. 파일은 UTF-8입니다.
- 즐겨찾기와 설정은 이 컴퓨터에만 저장되며 프로그램을 껐다 켜도 남아 있습니다.
  - Windows: `%APPDATA%\NAME ATELIER\name-atelier-data.json`
  - macOS: `~/Library/Application Support/NAME ATELIER/name-atelier-data.json`

## 설정

- 화면 테마: 시스템 / 라이트 / 다크
- 카드 전환 애니메이션: 켜기 / 끄기 (운영체제의 '애니메이션 줄이기'가 켜져 있으면 자동으로 꺼집니다)
- 즐겨찾기한 카드 자리 유지: 켜면 ☆한 카드는 다시 뽑아도 남고, 끄면 즐겨찾기는 보관만 하고 세 장 모두 새로 뽑습니다
- 사용법 다시 보기
- 이번 실행에서 본 이름 기록 비우기

## 알아 두세요

- 실제 문화권 이름은 공개 통계·자료를 참고해 검수한 목록에서 고릅니다. 한글 표기는 외래어 표기법을 기준으로 했지만, 실제 발음이나 역사·언어 관습과 완벽히 같다고 보장하지 않습니다.
- 생성된 이름이 실존 인물의 이름과 우연히 같을 수 있습니다.
- 성별 분류는 참고용입니다. 특정 성별만 쓸 수 있는 이름이라는 뜻이 아닙니다.

## 제거

- Windows 설치판: 설정 → 앱 → NAME ATELIER → 제거. 즐겨찾기 파일은 남으니 완전히 지우려면 위 데이터 폴더도 지웁니다.
- 휴대용: 압축을 푼 폴더를 지웁니다.
